# Fontes do Projeto

## Critérios de seleção

As fontes deste projeto são selecionadas considerando:

- **Relevância:** o conteúdo deve estar relacionado ao aprendizado de crochê.
- **Autoria:** deve ser possível identificar o autor, a organização ou o responsável pela publicação.
- **Clareza:** as explicações devem ser compreensíveis e, quando possível, acompanhadas de demonstrações.
- **Verificabilidade:** as informações devem poder ser conferidas no material original.
- **Complementaridade:** as fontes devem abordar assuntos diferentes ou apresentar explicações que se complementem.
- **Acessibilidade:** devem permitir consultar o conteúdo necessário para o estudo.

## 4. Avaliação das fontes

Uma fonte será considerada adequada quando seu conteúdo tiver sido consultado e for relevante para o objetivo do projeto.

A inclusão de um link nesta documentação não significa, por si só, que todo o conteúdo da fonte tenha sido verificado.

As fontes efetivamente importadas e utilizadas serão confirmadas durante a realização dos testes no notebook.

## 5. Uso responsável

Os links externos serão mantidos para permitir a consulta aos materiais originais. Os arquivos disponibilizados no GitHub deverão respeitar os direitos autorais e as condições de compartilhamento.

As respostas geradas pelo notebook serão verificadas por meio das citações, evitando tratar uma explicação da Inteligência Artificial como informação automaticamente correta.
