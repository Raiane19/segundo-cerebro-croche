# 🧶 Segundo Cérebro com IA — Crochê

## 📌 Sobre o projeto

Este projeto foi desenvolvido como parte de um desafio prático de aprendizagem com Inteligência Artificial, utilizando o Gemini Notebook (anteriormente conhecido como NotebookLM).

O objetivo é construir um caderno de estudos inteligente, especializado em crochê, que utiliza fontes selecionadas para explicar técnicas, pontos, materiais, abreviações e receitas de maneira organizada e acessível.

## 🎯 Objetivo

Criar um segundo cérebro com IA para aprender crochê do básico ao intermediário, utilizando fontes confiáveis em vídeo e texto para explicar materiais, pontos, abreviações, leitura de receitas e resolução de erros comuns, sempre indicando as fontes utilizadas.

## 🧠 O que o especialista estuda

- Materiais e ferramentas para iniciantes.
- Pontos fundamentais do crochê.
- Leitura e interpretação de receitas.
- Abreviações e convenções de escrita.
- Contagem de pontos e carreiras.
- Erros comuns e técnicas de acabamento.

## ⚙️ Diretriz do especialista

O notebook foi orientado a atuar como um assistente educacional especializado em crochê, com foco em iniciantes.

Suas principais regras são:

- Utilizar as fontes selecionadas como base das respostas.
- Apresentar citações que permitam verificar as informações.
- Explicar técnicas em etapas numeradas.
- Definir termos técnicos e abreviações.
- Identificar diferenças entre convenções quando houver fontes suficientes.
- Reconhecer quando as fontes não permitem confirmar uma informação.
- Criar exercícios e materiais de revisão baseados no conteúdo disponível.

A diretriz completa está disponível em [`planejamento/diretriz.md`](planejamento/diretriz.md).
